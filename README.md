# Low-Level Design (LLD) Problems

Java implementations of common LLD interview problems.

## Problems Implemented

- [x] [Elevator System](src/main/java/com/oshaklya/elevator/Notes.md)
- [x] Connect 4
- [x] Observer Pattern
- [x] Strategy Pattern

## Pattern

Each problem has a `Notes.md` file with:
- Requirements
- Entities & relationships
- Class design
- Implementation details & edge cases

See [Elevator Notes.md](src/main/java/com/oshaklya/elevator/Notes.md) for example.

## Setup

```bash
./gradlew build
./gradlew test
```
